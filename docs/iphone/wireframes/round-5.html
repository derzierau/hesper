Round 5: capture instead of the Search circle

The trailing circle next to the tab bar becomes the way to drop an idea or a task into Hesper: tap it and the phone records, speak, then start an agent now or keep it for later as a parked draft on a Mac. Search moves into the Agents tab, and the New agent accessory goes away, so there is one way in. Same tokens as round 4.

What changes in the concept

  • Tab bar: Inbox, Agents, Macs, and a capture circle in place of Tab(role: .search). The circle is a Liquid Glass button beside the TabView, not a tab, so tabs stay navigation only (HIG).
  • New agent accessory: removed. Capture is the one way to start or keep a task.
  • Search: .searchable on the Agents tab, same scope as before, on iPhone and iPad.
  • Keep for later: a parked draft (drafts.save with parked: true) on the chosen Mac, so it shows on that Mac's wall too. Drafts are local-only in hesperd today; reaching them over the relay is new core work.
